LEDAJANS SEO widget dosyaları — WordPress'te özel HTML veya Elementor HTML widget içine TÜM dosya içeriğini yapıştırın.

ÖNEMLİ — GÖRÜNÜM (blog ile aynı çizgi):
  Tüm sayfalar <div class="ledajans-seo-article"> ile sarılıdır. Stiller Ek CSS'te "Bölüm 13" olarak tanımlıdır.
  WP Admin → Görünüm → Özelleştir → Ek CSS → repo'daki Ek-CSS-final.css dosyasının GÜNCEL halini yapıştırın
  (en azından /* 13) SEO makale widget */ bloğu şart). Aksi halde kutu, tipografi ve turuncu CTA düzgün görünmez.
