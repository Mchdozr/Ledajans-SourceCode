## Findings (P0/P1)
1. **[BLOCKER] Etkilenen URL:** `https://ledajans.com/robots.txt` (sitewide etki)  
   **Sorun tipi:** Aşırı kısıtlayıcı robots direktifleri (`Disallow: /wp-content/plugins/`, `Disallow: /*.php$`) nedeniyle render/crawl sinyal kaybı riski  
   **Öncelik:** P0  
   **Dry-run sonucu:** Başarılı (kural bazlı simülasyonda CSS/JS erişim engeli oluşturabilecek direktifler izole edildi; üretim değişikliği uygulanmadı)  
   **Önerilen değişiklik:** `robots.txt` kural setini sadeleştir; sadece gerçekten private alanları blokla (örn. yönetim endpoint’leri), render için gerekli asset yollarını açık bırak.

2. **[BLOCKER] Etkilenen URL:** `https://www.ledajans.com/` (www host varyantı, canonical/redirect zinciri etkisi)  
   **Sorun tipi:** www varyantında sertifika/host doğrulama riski ve olası erişim tutarsızlığı  
   **Öncelik:** P0  
   **Dry-run sonucu:** Başarılı (konfigürasyon-dışı analizde risk doğrulandı; canlı TLS/redirect ayarına dokunulmadı)  
   **Önerilen değişiklik:** `www` ve apex için tekil kanonik host standardı belirle; TLS sertifika kapsamını ve 301 zincirini tek hop olacak şekilde normalize et.

3. **Etkilenen URL:** `https://ledajans.com/`  
   **Sorun tipi:** Mobil performans darboğazı (LCP/TBT yüksek) nedeniyle crawl bütçesi verimi ve dolaylı SEO performans riski  
   **Öncelik:** P1  
   **Dry-run sonucu:** Başarılı (Lighthouse çıktılarında darboğaz kalemleri doğrulandı: yüksek unused CSS/JS, ana iş parçacığı yükü)  
   **Önerilen değişiklik:** Kritik CSS ayrıştırma, kullanılmayan JS/CSS azaltımı, hero medya optimizasyonu ve üçüncü parti script yükleme stratejisi (defer/delay).

4. **Etkilenen URL:** `https://ledajans.com/` (ve snippet üreten ana landing şablonları)  
   **Sorun tipi:** Meta description uzunluğu nedeniyle SERP snippet kırpılması/CTR kaybı  
   **Öncelik:** P1  
   **Dry-run sonucu:** Başarılı (mevcut meta uzunluğu riskli aralıkta; canlı snippet testi yapılmadı)  
   **Önerilen değişiklik:** Ana sayfa description’ını niyet odaklı, 140-160 karakter bandında yeniden yaz; ticari sorgu uyumlu CTA ekle.

5. **Etkilenen URL:** `https://ledajans.com/llms.txt` (dosya yok, anasayfaya dönüyor)  
   **Sorun tipi:** AI crawler yönlendirmesi/politikası eksikliği (yardımcı SEO sinyali boşluğu)  
   **Öncelik:** P1  
   **Dry-run sonucu:** Başarılı (endpoint yokluğu tespit edildi; dosya üretimi planlandı, canlıya yazılmadı)  
   **Önerilen değişiklik:** `llms.txt` oluştur; şirket özeti, hizmetler, iletişim ve bot-politika sınırlarını açıkça tanımla.

## Dry-Run Patch Plan
1. Robots policy dry-run
   - Mevcut kural setini satır bazında risk sınıflandır: render-engelleyici / güvenli / gereksiz.
   - Simülasyon çıktısı: "yalnız yönetim URL’leri bloklu, asset erişimi açık" hedefi.
2. Host canonicalization dry-run
   - `www -> apex` (veya tersi) tek standart seç.
   - Redirect zinciri ve canonical sinyalinin tek hostta birleşmesini konfigürasyon taslağıyla doğrula.
3. Meta/snippet dry-run
   - Ana sayfa ve para sayfa şablonlarında description uzunluk denetimi.
   - 140-160 karakter bandına düşen alternatif metin varyantları üret.
4. Performance dry-run
   - Yüksek maliyetli CSS/JS varlıklarını listele (önce kritik path, sonra üçüncü parti).
   - Erteleme/ayrıştırma sonrası beklenen LCP/TBT kazanım aralığını tahminle.
5. `llms.txt` dry-run
   - Taslak dosya içeriğini doğrulama checklist’i ile gözden geçir (doğruluk, güncellik, politika netliği).

## Apply Plan

- Performans optimizasyonunda JS erteleme, etkileşimli bileşenlerde fonksiyonel regresyon riski taşır.
- Meta toplu revizyonunda niyet uyumu bozulursa CTR düşebilir; A/B varyant yaklaşımı önerilir.
- Bu rapordaki tüm P0 maddeler dry-run onayı olmadan canlıya alınmamalıdır.
